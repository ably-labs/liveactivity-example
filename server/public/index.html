FCM via Ably

Android devices activate with Ably push (FCM) and subscribe to an Ably channel in the app. Target them by channel — one publish reaches every subscribed device — or by the Ably Device ID shown in the app. Provide at least one. Every event carries the full game state, so the teams are sent each time.
